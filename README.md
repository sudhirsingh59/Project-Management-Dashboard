# Project Management Dashboard | Power BI Hackathon

## Overview
This project presents an interactive Power BI dashboard built using the provided hackathon dataset. It helps stakeholders monitor project portfolio health, evaluate delivery performance, analyze risks, and track benefits and strategic impact.

## Dashboard Pages

### 1. Executive Overview
Provides a high-level view of portfolio health, project status, progress, costs, and key performance indicators.

### 2. Project Performance
Analyzes planned versus actual progress and evaluates schedule and cost performance across the project portfolio.

### 3. Risk & Delivery Analysis
Highlights open and critical risks, overdue milestones, and important delivery challenges.

### 4. Benefits & Strategic Impact
Tracks forecast and realized benefits, benefit realization, programme performance, and strategic alignment.

## Tools & Technologies
- **Power BI** — interactive dashboard and visualizations
- **Python (Pandas)** — data exploration, cleaning, and analysis
- **SQL / PostgreSQL** — querying and validating project data
- **Microsoft Excel** — spreadsheet-based data review and analysis

## Project Workflow
1. Review the provided dataset.
2. Explore and analyze data using Python, SQL, and Excel where applicable.
3. Build interactive report pages in Power BI.
4. Present project performance, risks, and benefits through business-focused visualizations.

## Project Objective
To transform project management data into clear, actionable insights that support data-driven decisions and portfolio monitoring.

## Note
This project was developed for a hackathon using the provided dataset. The analysis and dashboard are intended for learning and portfolio demonstration.
